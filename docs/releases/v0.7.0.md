# ai-gram v0.7.0

`v0.7.0` is the regular public release for Telegram Bot API 10.1 support. It updates the library from Bot API 10.0-complete coverage to Bot API 10.1-complete coverage with typed Rich Messages, join request query helpers, and poll link media.

The module is still pre-v1, so public APIs may continue to evolve before `v1.0`.

## Status

- Release type: regular public release.
- Module version: `v0.7.0`.
- Telegram Bot API coverage: Bot API 10.1 complete with documented architecture differences.
- Source audit: [`docs/BOT_API_10_1_AUDIT.md`](../BOT_API_10_1_AUDIT.md), checked against the official Telegram Bot API changelog published on June 11, 2026.
- Sensitive, state-changing, and user-visible live smoke remains manual-only.
- Code generation was not introduced.

## Highlights

- Added Bot API 10.1 join request query support:
  - `bot.AnswerChatJoinRequestQuery`;
  - `bot.SendChatJoinRequestWebApp`;
  - `telegram.User.SupportsJoinRequestQueries`;
  - `telegram.ChatFullInfo.GuardBot`;
  - `telegram.ChatJoinRequest.QueryID`.
- Added Bot API 10.1 poll link media support:
  - `telegram.Link`;
  - `telegram.PollMedia.Link`;
  - `bot.InputMediaLink`;
  - `bot.MediaLink`.
- Added Bot API 10.1 Rich Message support:
  - `telegram.RichMessage`;
  - `telegram.RichText`, including plain strings, arrays, and all official rich text variants;
  - `telegram.RichBlock`, including all official rich block helper classes and block variants;
  - `telegram.Message.RichMessage`;
  - `bot.InputRichMessage`;
  - `bot.InputRichMessageContent`;
  - `bot.SendRichMessage`;
  - `bot.SendRichMessageDraft`;
  - `bot.EditMessageTextParams.RichMessage`.

## Compatibility Notes

No breaking pre-v1 rename is included in this release.

The new APIs are additive. Existing text-message, edit-message, inline query, guest query, Web App query, and poll APIs remain available.

`EditMessageTextParams` now accepts either `Text` or `RichMessage`. Existing text edits continue to use `Text`; rich edits must use `RichMessage` without `Text`.

`InputRichMessage` follows Telegram's contract: exactly one of `HTML` or `Markdown` must be set.

`SendRichMessageDraft` follows Telegram's stricter draft contract and accepts only a non-zero numeric private-chat `ChatID`.

## Install

Install the release with:

```bash
go get github.com/xDilettante/ai-gram@v0.7.0
```

After publishing, verify the release tag from an external temporary module with:

```bash
AIGRAM_CONSUMER_VERSION=v0.7.0 scripts/smoke_public_consumer.sh
```

If the public Go proxy has not observed the new tag yet, retry once with:

```bash
AIGRAM_CONSUMER_VERSION=v0.7.0 AIGRAM_CONSUMER_DIRECT=1 scripts/smoke_public_consumer.sh
```

## Manual-Only Live Smoke Areas

The following Bot API 10.1 areas must not be live-smoked automatically:

- `answerChatJoinRequestQuery` and `sendChatJoinRequestWebApp`, because they can affect real join requests or open Mini Apps;
- advanced poll option media, because it creates visible poll messages;
- Rich Message sends, edits, and drafts, because they mutate user-visible messages or drafts.

Existing manual-only areas from earlier releases still apply: payments, Stars, gifts, Passport, business account mutation, managed bot tokens, destructive chat/admin actions, sticker set mutation, lifecycle methods, webhook certificate upload, and webhook state changes.
